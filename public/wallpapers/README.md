# Toon wallpaper collection

Revision 3: the Imagegen output below was still too painterly, so every file is flattened with `scripts/toon-wallpapers.py` (mean-shift smoothing, a 12-colour poster palette, small islands merged, navy ink on every colour border). Revision 2: redrawn with the built-in Imagegen tool after the initial painterly images proved too realistic. Thick ink contours, simplified flat shapes, cel shading, halftone dots, and graphic hatching. Five choices, each with automatic day/night artwork. Final project assets are the ten adjacent WebP files at 1280px width.

## Exact revision prompts

### big-sur / light

Use case: style-transfer. Edit target: supplied Big Sur wallpaper. Keep the coastline/bridge composition and landscape identity, but REDRAW EVERYTHING as a boldly simplified 2D CARTOON comic-book wallpaper. The current image is TOO REALISTIC. Very thick dark navy ink outlines around every major shape, visibly hand-drawn rounded contours, flat poster colors, only TWO solid cel-shaded tones per material, playful chunky mountains, stylized scalloped foam, clouds like puffy comic shapes. A limited punchy turquoise/cobalt/mustard/green palette. Texture only sparse graphic halftone DOTS and short crosshatching confined to shadow patches. Detail through graphic shapes, NOT tiny naturalistic brush strokes. Think flat screen-printed Saturday morning cartoon background with neo-brutalist ink contours. No painterly rendering, no realistic water, no fine foliage, no photographic lighting, no smooth gradients, no 3D rendering. LIGHT DAYTIME. Single full-frame wide wallpaper, no text, frame, devices or UI.
